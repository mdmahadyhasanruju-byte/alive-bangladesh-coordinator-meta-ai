# Pen Writes Everything — aLive Bangladesh Coordinator Agent

**Bismillahir-Rahmanir-Rahim**

## Destiny

BiP'sPHDO's is the originating vision. meUus is its human development ecosystem: a person begins with **me**, discovers **U**, and grows toward **us**. aLive Bangladesh is the community coordination expression of that vision in Bangladesh: people identify local needs, listen to residents, connect evidence to decisions, make clear commitments, and follow through together. The long horizon is global adaptation that respects local languages, cultures, institutions, consent, and human authority.

This agent is intended to help coordinators turn field input into evidence-linked drafts for people to review. It does not decide what a community needs, assign responsibility without explicit evidence, promise services, or approve its own output.

## Creation pattern: Pen then KUN

The work follows **Pen → KUN**. First, write the purpose, truth boundaries, architecture, contracts, consent, language plan, compliance assumptions, and staged TODOs. Only after those are reviewed should implementation begin. “KUN” is the intended build stage, not a claim that a build exists or has been authorized by this document. Each later stage must preserve existing material, work from verified evidence, and pass its stated review gate.

## Intended end state

If the project is later approved, implemented, and verified, the intended system may include:

- A coordinator interface for consented text, audio, and optional photographs.
- Language-aware transcription and extraction using approved Meta models.
- Evidence links from every proposed need, description, commitment, and follow-up to source text or audio segments, with image hashes when images are used.
- Explicit uncertainty and missing-information fields; no invented people, dates, locations, or commitments.
- A draft generator that produces a structured, reviewable record.
- A human approval queue and an auditable approved ledger, with corrections and deletion handling.
- Bengali, English, and Arabic starting support, with architecture that can be localized for additional languages.
- Consent, access control, retention, deletion, and safe logging controls.
- A synthetic-data public demo and a narrow MVP suitable for testing the workflow.
- Documentation, reproducible verification evidence, and a separately reviewed path toward broader deployments.

These are intended outcomes, not current capabilities. No public deployment, integration, partnership, or release is established by this pen phase.
